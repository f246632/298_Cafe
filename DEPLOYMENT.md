## 🛠️ How to Update the Website

### 1. Update Menu Items

Edit `data/menu.json`:

```json
{
  "categories": [
    {
      "name": "Heiße Getränke",
      "icon": "coffee",
      "items": [
        {
          "name": "Kaffee",
          "description": "Frisch gebrühter Filterkaffee",
          "price": "2.50"
        }
      ]
    }
  ]
}
```

### 2. Update Reviews

Edit `data/reviews.json`:

```json
{
  "testimonials": [
    {
      "author": "Customer Name",
      "rating": 5,
      "text": "Review text here",
      "date": "2025"
    }
  ]
}
```

### 3. Add Real Photos

1. Take professional photos of:
   - Cafe interior
   - Food and cakes
   - Coffee preparation
   - Atmosphere

2. Optimize images:
   ```bash
   # Resize to web-friendly dimensions
   # Hero: 1920x1080
   # Gallery: 800x600
   # Compress for faster loading
   ```

3. Replace placeholders in HTML:
   ```html
   <!-- Current placeholder -->
   <div class="gallery-placeholder">
     <i class="fas fa-cake-candles"></i>
     <p>Hausgemachte Kuchen</p>
   </div>

   <!-- Replace with actual image -->
   <img src="images/optimized/cakes-1.jpg" alt="Hausgemachte Kuchen">
   ```

### 4. Deploy Updates

```bash

cd /Users/m./berlinwebsites/298_Cafe

# Make your changes, then:
git add .
```

## 🆘 Support & Maintenance

### Common Tasks

**Update text content:**
- Edit `index.html` directly
- Search for the text you want to change
- Save and push to GitHub

**Change images:**
- Add new images to `images/optimized/`
- Update `src` attributes in HTML
- Push changes to GitHub

**Modify colors/styles:**
- Edit `css/style.css`
- Test locally first
- Push changes to GitHub

### Troubleshooting

**Website not updating?**
1. Check GitHub Actions (may take 1-2 minutes)
2. Clear browser cache (Cmd+Shift+R on Mac)
3. Wait 5 minutes for CDN propagation

**Mobile menu not working?**
1. Check browser console for errors
2. Ensure `js/main.js` loaded correctly
3. Test on different devices

**Forms not submitting?**
- Form validation works locally
- For email submission, need backend service
- Current setup shows success message only
